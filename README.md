# Fieldnote Studio

Fieldnote Studio is a responsive four-page website for a fictional independent creative studio. It introduces the studio, shares its story and values, presents its services, and gives visitors a way to get in touch.

## Pages

- **Home** — Studio introduction, highlights, and calls to action
- **About** — The studio's story, mission, vision, and values
- **Services** — Brand strategy, visual identity, and digital experiences
- **Contact** — Contact details, office hours, and a client-side contact form

The contact form validates its required fields and displays a confirmation message. It does not send data to a backend.

## Built with

- React
- Vite
- React Router
- Plain CSS

## Getting started

Use Node.js and npm, then run these commands from this project directory:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173/`).

## Other commands

```bash
npm run build
npm run preview
npm run lint
```
